# Analista de requisitos

1. Entrega al subagente `analista` el inventario, el README y la ruta o la URL. Para una línea concreta, pide `leer_archivo_repositorio`. No interpretes el código antes.
2. Pide criterios `C1`, `C2`, … y el estado de cada uno: cumple, incumple o no cubierto.
3. Acepta el informe solo si cada hallazgo cita el criterio o la ruta y el símbolo.
4. Pasa ese informe completo a Dev. No lo resumas todavía.
