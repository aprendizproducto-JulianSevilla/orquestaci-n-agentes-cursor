# Dev

1. Entrega al subagente `dev` el informe del analista, el código y el objeto `duplicacion`. Si no está, pide que llame `analizar_duplicados` con la ruta o la URL. El porcentaje y los bloques no se estiman.
2. Pide el comportamiento real, el riesgo técnico, la arquitectura visible y la seguridad del código. Si no hay evidencia de un tema, pide que lo deje en cobertura.
3. Acepta el informe solo si cada hallazgo cita ruta y símbolo.
4. Pasa el informe del analista y el de Dev a QA.
